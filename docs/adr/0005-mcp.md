# ADR 0005: MCP integration

- Status: accepted
- Decision: discover tools from each configured MCP HTTP server, validate their JSON schemas, and expose them through a metadata-bearing proxy in a unified registry.
- Rationale: agents can use least-privilege tool allowlists while local sandboxes follow the same protocol as external servers.
- Consequence: production MCP services require scoped credentials and authenticated transport, which are not configured by the demo.
